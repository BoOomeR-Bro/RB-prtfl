# Персональный сайт-портфолио и резюме — Руслан Бабинов

> **IT Infrastructure Engineer | Инженер ИТ-инфраструктуры**  
> Проектирование, автоматизация и сопровождение серверных сред, сетей, виртуализации и внутренних сервисов.

Современный, адаптивный, высокопроизводительный сайт-резюме и техническое портфолио, разработанный в строгой инженерной эстетике (графитовый тёмный интерфейс, акценты терминального зелёного и технологичного голубого цветов).

---

## ⚡ Технологический стек

- **Фреймворк:** React 18 + TypeScript
- **Сборщик:** Vite 5
- **Стилизация:** Tailwind CSS 3 (с кастомной инженерной палитрой, сетками и поддержкой `prefers-reduced-motion`)
- **Иконки:** Lucide React
- **Инфраструктура & Деплой:** Docker (Multi-stage build), Nginx Alpine, Docker Compose

## 🚀 Быстрый запуск

### 1. Локальная разработка

Требуется Node.js 18+ или новее:

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с hot-reload
npm run dev
```

Сервер будет доступен по адресу: `http://localhost:3000` (или порту, указанному в консоли).

### 2. Сборка production-билда

```bash
# Проверка типов TypeScript и компиляция через Vite
npm run build

# Предпросмотр собранного production-билда
npm run preview
```

Скомпилированные статические файлы сохраняются в директорию `dist/`.

## 🐳 Запуск через Docker и Docker Compose

В проект включена оптимизированная многоэтапная сборка (Node 20 Alpine для сборки -> легковесный Nginx Alpine для отдачи статики):

### Вариант A: Через Docker Compose (рекомендуется)

```bash
# Сборка и запуск контейнера в фоновом режиме
docker compose up -d --build

# Просмотр логов
docker compose logs -f

# Остановка контейнера
docker compose down
```

Сайт будет доступен на порту `8080`: `http://localhost:8080`.

### Вариант B: Через прямой Docker build

```bash
# Сборка образа
docker build -t ruslan-portfolio:latest .

# Запуск контейнера на 80 порту (или 8080:80)
docker run -d --name ruslan-portfolio -p 8080:80 --restart unless-stopped ruslan-portfolio:latest
```

## 🌐 Размещение на VPS

1. **Клонируйте репозиторий** на ваш сервер:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> /opt/portfolio
   cd /opt/portfolio
   ```

2. **Запустите через Docker Compose**:
   ```bash
   docker compose up -d --build
   ```

3. **Настройте домен и SSL (Let's Encrypt / Certbot)** через хостовый Nginx или Traefik/Caddy:
   Пример проксирования через Nginx на хосте:
   ```nginx
   server {
       server_name yourdomain.ru;

       location / {
           proxy_pass http://127.0.0.1:8080;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```

## ⚙️ Редактирование информации

Вся информация о вашем опыте, контактах, стеке и проектах централизована в `src/data/`:
- `src/data/profile.ts` — контакты (email, телефон, локация), заголовки, факты, ссылки на внешние профили (Telegram/GitHub/LinkedIn).
- `src/data/competencies.ts` — список навыков и категорий.
- `src/data/experience.ts` — места работы, периоды, обязанности.
- `src/data/projects.ts` — реализованные проекты и инженерные кейсы.
- `src/data/education.ts` — образование, курсы и языки.
